# Flashcards Minimalist • Words & Collocations (IELTS)

Ứng dụng Flashcard cá nhân hóa tối giản với tông màu trung tính nhạt (pale neutral), thiết kế responsive hoàn hảo trên cả **Điện thoại** và **Máy tính**, hoạt động trực tiếp 100% trên **GitHub Pages** (không cần cài đặt server hay build phức tạp).

---

## ✨ Điểm Nổi Bật

1. **Phân loại thẻ ngay khi vào web:**
   - 📖 **Words (Từ đơn):** Định nghĩa, phiên âm quốc tế (IPA), ví dụ ứng dụng.
   - 🔗 **Collocations (Cụm từ cố định):** Các cụm từ học thuật tự nhiên, hỗ trợ diễn đạt tự nhiên cho IELTS Speaking & Writing.

2. **2 Chế độ tương tác linh hoạt:**
   - **Chế độ Lật thẻ (Flip Card):** Chạm hoặc nhấn <kbd>Space</kbd> để lật thẻ 3D mượt mà, hỗ trợ phát âm chuẩn bản xứ (Audio TTS).
   - **Chế độ Gõ từ (Interactive Typing Quiz):** Nhìn nghĩa tiếng Việt hoặc câu ngữ cảnh có chỗ trống, gõ từ tiếng Anh và hệ thống tự động kiểm tra đúng/sai, có nút gợi ý chữ cái đầu.

3. **Hệ thống lặp lại ngắt quãng (Spaced Repetition):**
   - ⏳ Chu kỳ ghi nhớ chuẩn khoa học: **1 ngày → 4 ngày → 7 ngày → 14 ngày**.
   - Khi bấm **"Đã nhớ" (hoặc phím 2)**: Thẻ tự động tăng cấp chu kỳ (1d → 4d → 7d → 14d).
   - Khi bấm **"Chưa nhớ" (hoặc phím 1)**: Thẻ lập tức quay về hộp 1 ngày để ôn luyện lại.
   - Bộ lọc thông minh: Lọc theo thẻ "Đến hạn hôm nay", thẻ "1 ngày", "4 ngày", "7 ngày", "14 ngày".

4. **Thiết kế tối giản trung tính (Pale Neutral Minimalist):**
   - Tông màu dịu mắt: Warm Alabaster, Sage & Slate, font chữ Plus Jakarta Sans hiện đại.
   - Hỗ trợ đổi sang giao diện trung tính tối (Dark mode).

5. **Độc lập & Bảo mật dữ liệu:**
   - Tự động lưu trên trình duyệt (`localStorage`).
   - Hỗ trợ **Xuất file JSON** (Export) để sao lưu hoặc chuyển đổi sang điện thoại/máy tính khác.
   - Hỗ trợ **Nhập file JSON** (Import) và khôi phục bộ thẻ mẫu bất kỳ lúc nào.

## ⌨️ Phím Tắt Tiện Lợi (Khi dùng trên máy tính)

- <kbd>Space</kbd>: Lật thẻ xem mặt sau / mặt trước.
- <kbd>Enter</kbd>: Kiểm tra kết quả khi gõ từ / Chuyển thẻ tiếp theo.
- <kbd>1</kbd>: Đánh dấu "Chưa nhớ" (xếp lại vào chu kỳ 1 ngày).
- <kbd>2</kbd>: Đánh dấu "Đã nhớ" (tiến lên chu kỳ tiếp theo: +4d, +7d, +14d).
- <kbd>←</kbd> / <kbd>→</kbd>: Lùi / Tiến giữa các thẻ flashcard.
- <kbd>Esc</kbd>: Đóng cửa sổ pop-up (Thêm thẻ / Quản lý thẻ).

## 🚀 Hướng Dẫn Kích Hoạt GitHub Pages (Chạy Web Trực Tiếp Miễn Phí)

### Bước 1: Tạo Repository mới trên GitHub
1. Đăng nhập vào [GitHub](https://github.com/) với tài khoản của bạn (`chamlai123`).
2. Nhấn nút **New** (Tạo repo mới).
3. Đặt tên Repository, ví dụ: `flashcards` (chọn Public).
4. Nhấn **Create repository**.

### Bước 2: Đẩy mã nguồn lên GitHub
Mở terminal tại thư mục này và chạy các lệnh sau:
```bash
git remote add origin https://github.com/chamlai123/flashcards.git
git branch -M main
git push -u origin main
```

*(Lưu ý: Thay `flashcards` bằng tên repo bạn vừa tạo nếu đặt tên khác)*

### Bước 3: Bật GitHub Pages
1. Trên giao diện GitHub của repo, vào tab **Settings** (Cài đặt) → Chọn mục **Pages** ở thanh menu bên trái.
2. Tại phần **Build and deployment** > **Branch**:
   - Chọn nhánh: `main`
   - Chọn thư mục: `/ (root)`
3. Nhấn **Save**.
4. Chờ khoảng 1-2 phút, GitHub sẽ hiển thị đường dẫn trang web của bạn:
   👉 **`https://chamlai123.github.io/flashcards/`**

Bạn có thể lưu bookmark link này trên điện thoại (thêm vào màn hình chính Home Screen như một App) hoặc máy tính để học mỗi ngày bất cứ nơi đâu!
