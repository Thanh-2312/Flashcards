Đồng Bộ Đám Mây (Phone ⇄ PC)

Đồng bộ tức thì bằng Google Firebase Realtime Database

Chưa kết nối Firebase
Chưa đồng bộ
Hướng dẫn tạo Firebase miễn phí (chỉ làm 1 lần)
  1. Truy cập Firebase Console và nhấn Add project (miễn phí 100%).
  2. Trong menu trái, chọn Build Realtime Database Bấm Create Database.
  3. Chọn vị trí (Singapore hoặc US) Chọn Start in test mode (quyền read/write: true).
  4. Sao chép đường dẫn Database URL (dạng https://<ten-du-an>.firebaseio.com/) dán vào ô cấu hình ở trên và bấm Lưu & Kết nối!

Link có cả Firebase và API key. Mở link bằng Safari hoặc Chrome trên điện thoại; nếu dùng app ở Màn hình chính thì dán link vào ô Cấu hình Firebase ở trên rồi bấm Lưu. Không gửi link này cho người khác.

Cài Đặt AI (Google Gemini)

Dùng để dịch câu đàm thoại và chấm chữa bài nói IELTS Speaking

Chưa kết nối Google Drive
Cách lấy Gemini API Key miễn phí (không cần thẻ)
  1. Truy cập Google AI Studio (aistudio.google.com) và đăng nhập bằng tài khoản Google.
  2. Nhấn vào "Get API key" ở thanh menu bên trái Bấm "Create API key".
  3. Sao chép chuỗi mã (bắt đầu bằng AIza...), dán vào ô ở trên và nhấn Lưu Cấu Hình!
Cách tạo Google Drive Client ID trong 3 phút
  1. Truy cập Google Cloud Console (Credentials).
  2. Bật Google Drive API tại mục "APIs & Services" "Library".
  3. Tại Credentials, chọn Create Credentials OAuth client ID (Loại: Web application).
  4. Thêm URL của bạn vào Authorized JavaScript origins: https://thanh-2312.github.io và http://localhost:5500.
  5. Sao chép Client ID dán vào ô trên và nhấn Kết Nối Drive!
